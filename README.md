# Space Ball

3D platformer for mobile made in Unity: jump from platform to platform through several levels and beat your score. I modelled the levels, programmed the jump mechanics and the scoring system.

**Play in the browser:** [lab.jzmarquez.com/en/space-ball](https://lab.jzmarquez.com/en/space-ball/) · **Android:** [APK in Releases](../../releases/latest) · **Gameplay video:** [YouTube](https://www.youtube.com/watch?v=7Ij2qMfMZoE)

## Controls

Arrow keys or WASD; on a phone, the on-screen joystick. Collect the points and jump onto the teleporter to reach the next level.

## Project

Opens with **Unity 2022.3.62f3** (`ProjectSettings/ProjectVersion.txt`): add the folder in Unity Hub. The game was made in 2021 with an older Unity version and kept as a `.unitypackage`; this project tree was rebuilt from that package. Packages don't carry project settings, so the tags and the scene list in Build Settings were restored from the scenes. Scenes: `Escene 1`, `Escene 2` and `END`. Build target: Android (the APK in Releases) or WebGL.

## Not included

These third-party files were in the original project but may not be redistributed, so they are left out. The scenes still reference them: import them again to get the original look.

- *Joystick Pack* (Fenerax Studios, free on the Unity Asset Store): the on-screen joystick
- Downloaded textures: metal, wood, road barrier and striped wall, the space background and the hoop animation (`Pictures/`)
